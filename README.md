# Yugotaria: Civil War

Покроковий гексовий варгейм про громадянську війну трьох фракцій (Соціалістична влада,
Демократичні повстанці, Націоналістичні повстанці). Гра — один HTML-файл без залежностей:
відкривається просто в браузері, гра hot-seat з туманом війни.

## Як запустити

**У браузері, без встановлення:** https://idologonia.github.io/Ugotarian_WarGame/
(публікується автоматично з гілки `main`, див. нижче).

**З диска:** завантажте файл [`dist/Yugotaria-Civil-War.html`](dist/Yugotaria-Civil-War.html)
(кнопка «Download raw file» на GitHub) і відкрийте його в браузері. Інтернет потрібен лише
для шрифтів — без нього гра працює зі звичайними.

**Із вихідного коду** (потрібен Node.js 18+):

```bash
git clone https://github.com/idologonia/Ugotarian_WarGame.git
cd Ugotarian_WarGame
node build.js                 # зібрати dist/
npm test                      # зібрати + усі тести правил (≈25 с)
```

Потім відкрийте `dist/Yugotaria-Civil-War.html` у браузері.

### Публікація на GitHub Pages

Workflow `.github/workflows/pages.yml` на кожен пуш у `main` збирає гру, проганяє тести й
викладає її на Pages (головна сторінка — гра, старі етапи — у `releases/`). Один раз
треба ввімкнути: **Settings → Pages → Build and deployment → Source: GitHub Actions**,
потім **Actions → «Збірка й публікація гри» → Run workflow** (або будь-який пуш у `main`).

Потрібен лише Node.js (18+). Для UI-тестів — ще Python 3 з `pip install playwright`.

```

                         CONFIG.unresolved — параметри-заглушки, що чекають рішення автора
  02_hex_rng.js          геометрія гексів (odd-q), детермінований ГВЧ, шум, купа для A*
  03_mapgen.js           генерація тестової карти з seed
  04_scenario.js         тестовий сценарій: склад сил, створення підрозділів
  05_engine.js           ядро: фази, години, маршрути, рух, накази, контроль
  06_intel.js            розвідка й туман війни
  07_combat.js           бій, мораль, втрати
  07b…07i                транспорт, трофеї, логістика, політика, інженерія,

  08_save.js             збереження (localStorage), версії формату
  08b_view.js            картина фракції для онлайн-гри (строгий туман війни)
  09_ai.js               боти: легкий і важкий рівень (див. нижче)
  85_net.js              клієнт онлайн-гри: лобі, накази через сервер, чат
  90_ui.js               інтерфейс (canvas + DOM); лише читає стан і викликає модулі
  index.template.html    розмітка й стилі; /*SCRIPT*/ замінюється кодом
dist/
  Yugotaria-Civil-War.html   самостійна сторінка (відкривати її)
  yugotaria.html             та сама гра без doctype — для публікації як Artifact
releases/                знімки попередніх етапів (stage1 … stage4c)

  *.test.js              тести правил (Node, без UI); load.js вантажить модулі у vm
  run.js                 раннер: паралельно, з підсумком
```

Модулі правил (`01`–`08`) не звертаються до DOM — їх можна тестувати в Node.
Усі розрахунки детерміновані: ті самі дії дають той самий результат
(замість `Math.random` — `hash2` від seed і ходу).

## Боти

У головному меню для кожної фракції обирається людина, легкий або важкий бот
(`state.players`; старі збереження без цього поля — гра людей). Режими:
кілька людей — «гаряче місце» з передачею ходу; одна людина — боти ходять одразу,
карта завжди показана її очима; без людей — режим глядача (пауза, крок, темп, погляд).

Бот (`src/09_ai.js`, `AI.runPhase(state)`) діє лише у фазі своєї фракції, через ті самі
функції, що й гравець, і знає про противника тільки з `Intel.knownList` своєї фракції.
Рішення детерміновані. Пам’ять бота — `state.ai`, зберігається разом із грою.

- **Легкий:** кожен підрозділ іде до найближчого чужого пункту, стріляє в першого видимого
  ворога, частина сидить у своїх пунктах.
- **Важкий:** тримачі центрів пунктів (пункт належить тому, хто тримає центр), надзвичайна
  оборона своїх пунктів, розподіл ударних сил між цілями із зобов’язанням на 4 год,
  збір перед відомим сильнішим противником, зосереджений вогонь з урахуванням сил поруч,
  відступ зламаних, поповнення, підвезення піхоти, набір нових підрозділів, дипломатія.

Порівняння (24 год, 10 карт, кожна фракція по черзі важким ботом проти двох легких):
важкий тримає в середньому 2,2–2,3 пункту проти 2,0 у легкого на тому самому місці.

## Нове в цьому оновленні

- **Засідка** підпускає ворога до найближчої точки його маршруту, б’є всіма засідниками, що
  дістають (вогневий мішок), шквальним вогнем з укриття; перший вогонь ×1,6, відповідь ×0,4
  (`CONFIG.combat.ambushPosition*`).
- **Торгівля СВ з РФ** (вікно «Економіка»): закупівля (офіційні запити, РФ може відмовити) і
  продаж нафти, пального, боєприпасів і зброї через перехід «Росія» (`CONFIG.russiaTrade`).
- **Об’єкти поза пунктами**: заводи боєприпасів і зброї, польові склади фракцій на трасах і
  покинуті об’єкти стоять біля доріг за 3–6 гексів від пунктів. Разом із селом не переходять —
  їх треба брати окремо, утримавши гекс.

## Онлайн-гра (сервер на ПК хоста)

Ваш ПК — сервер; друзі грають у браузері за посиланням. Кожен бачить лише свою сторону:
сервер не передає браузеру ні невидимих ворогів, ні чужої економіки, розвідки чи мін —
підглянути через інструменти розробника нема чого. Порожні сторони грають боти.

### 1. Запуск сервера (Windows)

1. Встановіть **Node.js** версії LTS з <https://nodejs.org> (один раз; сторонні бібліотеки не потрібні).
2. Завантажте гру: на GitHub **Code → Download ZIP**, розпакуйте (або `git clone`).
3. Двічі клацніть **`start-server.bat`**. Відкриється вікно сервера й браузер зі сторінкою хоста.
   Вікно не закривайте, поки граєте. Windows може спитати про брандмауер — дозвольте доступ.
   - Інший порт: `start-server.bat --port 9000`. Linux/macOS: `./start-server.sh`.
4. У лобі: оберіть, хто керує кожною стороною (гравець чи бот), займіть свою, дочекайтеся
   друзів, натисніть **«Почати кампанію»**.

Посилання хоста (`…/?host=…`) — лише для вас: воно дає права керувати лобі. Друзям давайте
адресу без `?host=`.

### 2. Як друзям підключитися через інтернет

Оберіть один спосіб — сервер працює звичайним HTTP, тож підходить будь-який:

- **Cloudflare Tunnel — найпростіше, без акаунта й налаштування роутера.**
  Встановіть: `winget install --id Cloudflare.cloudflared`, потім у новому вікні:
  `cloudflared tunnel --url http://localhost:8080`. Він покаже адресу виду
  `https://….trycloudflare.com` — надішліть її друзям. Адреса нова при кожному запуску.
- **playit.gg** — безкоштовний тунель із постійною адресою: створіть тунель на
  `localhost:8080` і дайте друзям його адресу.
- **Tailscale** — усі встановлюють Tailscale і входять у вашу мережу; друзі відкривають
  `http://<ваша-адреса-Tailscale>:8080`.
- **Проброс порту на роутері** — TCP 8080 на локальну адресу вашого ПК (її показує вікно
  сервера); друзі відкривають `http://<ваша-зовнішня-IP>:8080`. Не працює, якщо провайдер
  не дає «білої» IP-адреси.
- **Та сама Wi‑Fi/мережа** — адреса `http://<локальна-IP>:8080` з вікна сервера.

### 3. Під час гри

- Хід іде фазами, як завжди: свою фазу граєте ви, решту — інші гравці й боти (на сервері).
- **Чат** — кнопка «Чат»: усім або лише одній стороні (для дипломатії).
- **«Меню»** відкриває лобі: склад сторін, гравці, чат; хост — збереження, завантаження,
  заміна гравця ботом, завершення гри.
- Збереження: `server/saves/` — автоматично щогодини гри й при зупинці сервера (Ctrl+C).
  Після перезапуску хост завантажує `autosave.json` у лобі, а гравці повертаються на свої
  сторони автоматично (браузер пам’ятає їх).
- Сайт гри на GitHub Pages працює як і раніше — для гри на одному ПК і з ботами.

## Політика, підтримка з-за кордону, фронт

- **Рішення** (Політика → Рішення, `src/07k_decisions.js`): курс сторони — умови, ціна,
  тривалість, одне активне. Повстанці: «Канал зв’язку» → «Спільний штаб» → «Єдиний фронт».
  СВ: «Амністія» для ДП або НП (розкол фронту), «Загальна мобілізація», «Введення російської
  армії» (ескалація → відповідь НАТО). ДП: «Повітряна розвідка НАТО», «Західна місія».
  НП: «Мобілізація діаспори».
- **Спонсори й добровольці окремо від ПВК**: стосунки — з державою-спонсором (Росія / Країни
  НАТО / Закордонна діаспора); добровольці — від своєї спільноти; ПВК — найманці за гроші.
  Іноземні інвестиції повстанців — у вікні «Економіка».
- **Порт СВ** — на узбережжі ближче до середини карти. **Аеропорт ДП** (`07j_air.js`) — смуга
  на 3 гекси: швидші вантажні рейси й база **БПЛА RQ-1 Predator** (розвідка району на годину).
- **Блокпости** (інженери, лише на дорозі): зупиняють ворожі колони, пост бачить далі.
- **Цивільні колони й біженці** (`07l_civil.js`): видно на карті; гуманітарний коридор дає
  захищену евакуацію; обстріл колони — удар по підтримці й репутації, порушення коридору.
- **Боти** користуються всім цим: рішення, ПВК, добровольці, інвестиції, закупівлі РФ,
  Predator, охорона й рейди на об’єкти поза пунктами, засідки на дорогах, блокпости,
  буксирування Д-30 тягачем; важкий бот не стріляє по колонах біженців.

## Команди

| Команда | Що робить |
|---|---|
| `npm run build` | збирає `dist/` (з перевіркою синтаксису) |
| `npm test` | збірка + усі `test/*.test.js` |
| `node test/run.js combat ew` | лише тести, в назві яких є `combat` або `ew` |
| `npm run test:ui` | збірка + UI-тести (Python + Playwright) |
| `npm run release -- stage5` | збірка + копія в `releases/Yugotaria-Civil-War-stage5.html` |
| `npm run balance` | таблиця дуелей для балансу |

UI-тести можна прогнати проти старого релізу:
`YUGO_GAME=releases/Yugotaria-Civil-War-stage4c.html python3 test/run_ui.py`.
Скриншоти пишуться в `test/out/` (не в git).

### Відомі застарілі UI-тести

UI-тести запускають гру з `#quickstart` (одразу гра трьох людей, без меню); `ui13_test.py`
перевіряє меню й ботів.

`ui_test.py`, `ui3_test.py` написані до появи екрана передачі ходу, а `ui11_test.py`
шукає вільне село в зоні міномета, якого на поточній карті немає. Вони падають і на
оригінальній збірці 4c — їх треба оновити або прибрати.

## Продуктивність

Найдорожче — малювання карти (до ~4800 гексів на екрані). Статичний шар (місцевість,
контроль, сітка, річки, дороги, назви, постачання) малюється одним `fill()` на колір і
кешується в окремому canvas. Наведення миші, превʼю маршруту й виділення малюються
поверх готового зображення. Кеш скидається в `renderAll()` (будь-яка дія гравця) і при
зміні вигляду (зсув, масштаб, перемикачі). Якщо додаєте код, що змінює карту без
`renderAll()`, викличте `invalidateBase()`.

Ядро правил швидке: година гри ≈ 6 мс, маршрут ≈ 1 мс, нова гра ≈ 11 мс (у браузері).
